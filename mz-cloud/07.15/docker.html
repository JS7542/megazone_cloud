Docker 소개

Docker는 애플리케이션과 실행 환경을 컨테이너 이미지로 패키징하여 개발, 테스트, 배포 환경의 차이를 줄여주는 컨테이너 플랫폼입니다.

핵심 구성 요소

구성 요소 핵심 역할
Docker Image 애플리케이션 실행에 필요한 파일과 설정을 포함하는 읽기 전용 템플릿입니다.
Container 이미지를 기반으로 실행되는 격리된 프로세스 환경입니다.
Dockerfile 이미지를 자동으로 빌드하기 위한 명령과 설정을 정의합니다.
Registry Docker Hub 또는 Amazon ECR처럼 이미지를 저장하고 배포하는 저장소입니다.
