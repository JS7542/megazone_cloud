MySQL 소개

MySQL은 관계형 데이터 모델과 SQL을 기반으로 데이터를 저장하고 조회하는 대표적인 오픈소스 관계형 데이터베이스 관리 시스템입니다.

주요 특징

항목 설명
관계형 데이터 테이블, 행, 열 구조를 사용하여 정형 데이터를 체계적으로 관리합니다.
SQL 지원 SELECT, INSERT, UPDATE, DELETE 등의 SQL 문으로 데이터를 처리합니다.
트랜잭션 InnoDB 엔진을 통해 데이터 일관성과 안전한 트랜잭션 처리를 지원합니다.
클라우드 연동 Amazon RDS, Lambda, API Gateway 등 AWS 서비스와 연동하여 웹 애플리케이션의 데이터 계층을 구성할 수 있습니다.
