# Dockerfile : 이미지 생성 설계 파일의 기본 파일명 =======================================================================
# FROM : 베이스 이미지 지정(태그 포함)
# WORKDIR : 컨테이너 내부 작업 디렉토리 지정, 컨테이너 내부의 기준 경로
# COPY : 컨테이너 내부로 파일 및 디렉토리 복사
# ADD : COPY 와 유사하지만, (tar,zip 압축 파일을 지정하면 압축을 해제하면서 복사한다.)
# RUN : 컨테이너 내부에서 명령어 실행, 설치 및 설정
# CMD : 컨테이너 시작 시 실행할 명령어 지정. 주로 서비스 실행에 사용
# ENTRYPOINT : 컨테이너 시작시 실행할 명령어, CMD 와 함께 사용.
# FastAPI 의 경우 ENTRYPOINT 와 CMD 를 같이 쓰는것을 권장한다.
# EXPOSE : 컨테이너 외부로 노출할 포트 정의(선택 사항, 가시성 확보 차원, 의미 없다 - 실제 서비스에는 영향을 주지 않는다.)
# ENV : 환경 변수 설정, 컨테이너 내부에서 사용 가능

# ==========================================================================================================================

# 도커 파일 빌드 ============================================================================================================
# 도커파일 빌드 명령어
# docker build -t <이미지명>:<태그> <도커파일 경로>

CMD["nginx","-g","demon off;"] : nginx 를 foreground 로 실행, 컨테이너가 종료되지 않도록 함.

nginx 명령어
-t	: nginx.conf문법에 오류가 없는지 테스트
-s reload : nginx를 종료하지 않고, 설정을 실시간으로 반영

nginx Dockerfile

# 1. 기본 이미지설정
FROM nginx:1.31.3-alpine

# 2. 컨테이너(기본 이미지) 내부 명령어
RUN rm /etc/nginx/conf.d/default.conf

# 3. 컨테이너 내부로 파일 복사
COPY ./default.conf /etc/nginx/conf.d/default.conf
# 4. HTML 내의 파일 및 디렉토리를 컨테이너로 복사
COPY ./html/ /usr/share/nginx/html/

# 5. 컨테이너 포트 정의
EXPOSE 80

# 6. 컨테이너 시작 시 실행할 명령 구성
CMD ["nginx", "-g", "daemon off;"]

위의 키-벨류 값 은 기존에 있던걸 고르는 것이 아닌, 사용자가 목적에 맞게 임의로 값을 지정해준다.
