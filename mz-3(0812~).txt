docker rm -f $(docker ps -aq)
	- 도커의 모든 id를 받아와서 삭제한다.
	
ps / images 옵션

	-a : 전체
	-q : id 값
	-l : 마지막에 실행한 컨테이너
	-n(Num) : 컨테이너 마지막에 설치된 Num 개의 컨테이너


rm - 컨테이너 삭제 / rmi 이미지 삭제
	rm 옵션은 가능한한 사용하지 않는게 좋다.
	-v 연결된 볼륨까지 삭제
	-f 강제 삭제

컨테이너로 db 생성시 데이터베이스, 사용자 등을 설치하면서 만들수 있다.
입력받는 root의 비밀번호 감추기 : read -s ROOT_PASSWORD

docker run -d --name mydb -p 3306:3306 -e MYSQL_ROOT_PASSWORD=$ROOT_PASSWORD \
mysql:8.0 --character-set-server=utf8mb4 --collation-server=utf8mb4_unicode_ci

docker exec -it mydb mysql -u  root -p 

컨테이너 이름뒤에 오는 명령어들은 컨테이너 내부에서 실행할 명령어들이다.
